# TACU brand assets

TACU's public identity combines the friendly terminal-companion mascot with restrained developer-tool typography.

## Name and language

- Product name: **TACU**
- Expansion: **Terminal Ally & Companion Unit**
- Repository, Python package, and import: `tacu`
- Canonical executable: `ticu`
- Convenience alias: `ti`
- Tagline: **Local-first AI for the terminal.**

## Palette

| Role | Color | Hex |
|---|---|---|
| Terminal background | Charcoal | `#15181D` |
| Primary copy and terminal outline | Warm off-white | `#F5F1E8` |
| Native-tool and local-model accent | Mint teal | `#62D6A8` |
| Companion heart and callout accent | Coral | `#FF6B6B` |

Use the mint and coral accents sparingly. TACU should look like a trustworthy terminal utility, not a generic neon AI product.

## Files

- `tacu-logo.png` — transparent square logo for README, avatar, and compact placements.
- `tacu-social-preview.png` — 1280×640 solid-background GitHub social preview.

## Usage rules

- Write the public product name as `TACU`, not `Tacu` or `tacu`.
- Keep the full expansion exactly as “Terminal Ally & Companion Unit.”
- Do not recolor, stretch, rotate, or crop away the prompt, face, or heart.
- Keep enough clear space for the mascot to remain readable at small sizes.
- Do not add circuit brains, robot heads, AI sparkles, or blue-purple gradients to the core identity.
- Use the social-preview file as supplied in GitHub repository settings; do not place it inside README content.
